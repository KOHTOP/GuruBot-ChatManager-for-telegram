#Чат менеджер Guru
Кто такой гуру? Гуру - это чат менеджер с интегрированной AI (gemini 2.0), который имеет функционал чат-менеджера, а также игровые механики. Бот поднимает актив в вашем чате, людям станет интереснее общаться в чате. 

#Guru-AI
